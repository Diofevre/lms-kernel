# Architecture Decision Records (ADR)

Les ADRs documentent **pourquoi** une décision architecturale a été prise.
Ils sont immuables — une décision prise est archivée, jamais modifiée.
Si une décision change, on crée un nouvel ADR qui supersède le précédent.

## Format

Chaque ADR est un fichier `NNNN-titre-court.md` dans ce dossier.
